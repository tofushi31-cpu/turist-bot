# Статус проекта turist-bot

Обновлено: 2026-08-07

## Работает
- Бот @fastto42_bot: каталог туров с фото, бронирование, уведомления админам
- Кнопка «Связаться с нами» (`/contact`) — сообщение клиента пересылается админам
- База броней (bookings.db), статусы, напоминания за 3/1 день
- Справка по визам — только Турция (Таиланд и Вьетнам убраны 06.08)
- Валюта цен настраивается (рубли/доллары)
- Watchdog: следит за единственным экземпляром бота, шлёт алерт в Telegram при падении/дублях/нестабильной связи с Telegram API
- **Google Sheets** (sheets.py) — реально работает с 06.08. До этого был баг: `load_dotenv()` вызывался после `import sheets`, поэтому переменные из `.env` не успевали подгрузиться и синхронизация тихо пропускалась при каждом обычном перезапуске бота. Из-за этого брони с #6 (10.07) не попали в таблицу — они там и не появятся, пока не дозаписать вручную
- Админка: доступ есть у Baga и у сестры (её Telegram ID добавлен 06.08)
- Репозиторий публичный: https://github.com/tofushi31-cpu/turist-bot
